# REQ-ANA-01 — Дальность приёма

**Подсистема:** Расчётные характеристики (не аппаратура)
**Реализация:** `sim/scripts/link_budget.py` → `out/link_budget.json`, `out/link_budget.svg`

- **Требование:** Определить дальность приёма для каждого антенного канала по формуле Фрииса с учётом шумовой дорожки и реальных потерь.
- **Проверка:** `tests/requirements/reception/test_reception.py` — 19 тестов.

### Сквозной расчёт физики

Максимальная дальность по формуле Фрииса:

R_max = (λ / (4π · R_sens^(1/4))) · √(G_tx · G_rx)

где R_sens — предел обнаружения приёмника (MDS), G_tx — усиление
передатчика (задано EIRP = +30 дБм).

Определяющие параметры:

| параметр | значение |
|---|---|
| шумовая дорожка | −136.16 дБм (k·T·B·F, B = 2.7 кГц, NF = 3.5 дБ) |
| MDS (SNR = 10 дБ) | −126.16 дБм |
| EIRP (эталон) | +30 дБм |
| запас на потери в тракте | 20 дБ |

### Результат по каналам

| канал | f | G_rx | радиовидимость | с запасом 20 дБ |
|---|---|---|---|---|
| A — печатная змейка | 200 МГц | −3.1 дБи | 9821 км | **982 км** |
| Б — решётка 2×2 | 2.45 ГГц | +9.0 дБи | 1249 км | **125 км** |
| В — решётка 4×4 | 5.8 ГГц | +12.7 дБи | 1053 км | **105 км** |

Значение «радиовидимость» — предел в свободном пространстве.
Значение «с запасом 20 дБ» — реалистичная оценка с учётом потерь
на атмосфере, многолучевость, загрязнение и рассогласование.

Значения также продублированы в столбце `Reception_Distance_m`
файла `requirements_matrix.csv`.
