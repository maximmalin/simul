# tests/requirements/ao/
Тесты акустооптического процессора по матрице требований (REQ-07/08/09/11/13/14/15).

## Что тестируется
- REQ-07: полупроводниковый лазерный диод λ = 650 нм (или 532 нм)
- REQ-08: стабильность оптической мощности не хуже 0.5%
- REQ-09: наличие цепи автоматического регулирования мощности (АРМ), класс безопасности лазера 3B
- REQ-11: кристалл диоксида теллура TeO₂, оптимизированный под медленную сдвиговую волну
- REQ-13: КМОП-матрица ≥ 2048 пикселей, динамический диапазон пикселя ≥ 72 дБ, частота считывания строк ≥ 50 кГц (EMVA 1288)
- REQ-14: динамический диапазон пикселя ≥ 72 дБ
- REQ-15: частота считывания строк ≥ 50 кГц

## Как запускать
.venv/bin/pytest tests/requirements/ao/ -v
