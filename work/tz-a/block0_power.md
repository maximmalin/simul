# Блок 5З: Система живлення 5В (розподіл по зірці + СВЧ-дроссели)

## 1. Загальні відомості

| Параметр | Значення |
|----------|-----------|
| Розташування в схемі | Відокремлений блок живлення (стежок зірки) |
| Призначення | Живлення всіх підсистем системи без наводок та імпульсних перевантажень |
| Режим роботи | Постійний струм, стабільна напруга 5В |

## 2. Вхідні вимоги

### 2.1. Джерело живлення
| Параметр | Значення | Норма |
|----------|-----------|-------|
| Напруга харчування | 7.4В (2S Li-Po) або 11.1В (3S Li-Po) | Залежить від конфігурації батареї |
| Ємність батареї | ≥ 2000 мА·год | Для автономної роботи ≥ 2 год |
| Внутрішній опір батареї | ≤ 50 мОм | Для мінімізації падіння напруги |
| Схема захисту | Захист від перевантаження та розрядки | Вбудований у BMS або окремий модуль |

### 2.2. Навантаження
| Блок | Напруга | Максимальний струм | Примітка |
|------|---------|---------------------|-----------|
| ESP32 (цифровий) | 5В | ≤ 1.5 А (піково) | Buck-конвертер |
| Аналогова частина (кварц, лазер, ОУ, STM32 АЦП) | 5В стерильне | ≤ 100 мА | LDO |
| СВЧ-тракт (тунер, мікшери, КТ368А) | 5В стерильне | ≤ 150 мА | LDO |
| Підсистема живлення (блок 5З) | - | - | Самоконтроль |

### 2.3. Коефіцієнт запобіжника
- Запобіжник F1: 2 А (поза батареї)
- Запобіжник F2: 1 А (на виході LDO)

## 3. Вихідні вимоги

### 3.1. Напруга живлення
| Параметр | Типова | Максимальна відхилення |
|----------|--------|------------------------|
| U_out (збірне) | 5.00 В | ±5% (4.75–5.25 В) |
| U_out (цифрова частина) | 5.00 В | ±3% (4.85–5.15 В) |
| U_out (аналогова частина) | 5.00 В | ±1% (4.95–5.05 В) |

### 3.2. Когерентність живлення
| Параметр | Витримка | Допуск |
|----------|----------|--------|
| U-noise (шум на виході LDO) | ≤ 10 мВ (pile-to-pile) | 1 мВ |
| U-noise (шум на виході Buck) | ≤ 50 мВ (pile-to-pile) | 5 мВ |
| U-ripple на частотах ≥ 10 МГц | ≤ 1 мВ | 0.1 мВ |

### 3.3. Коефіцієнт потужності
- λ-подібні пікові навантаження (Wi-Fi burst): ≤ 20 мс
- Дещо змінні: звичайно 50–200 мА постійно
