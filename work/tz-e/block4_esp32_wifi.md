## 1. ОБЩИЕ СВЕДЕНИЯ

### 1.1. Наименование изделия
**Цифровой мост ESP32 + PCB-антенна (отсек 4)** — узел 4.x структурной схемы `structural.drawio`.

### 1.2. Область применения
Приём оцифрованного радиопотока по SPI (4.0 MSPS, 18 МГц) от STM32 (отсек 3), буферизация во внутренний кольцевой буфер ОЗУ, передача данных на ноутбук оператора через встроенную текстолитovую PCB-антенну (Wi-Fi) сквозь радиопрозрачное пластиковое окно в торце алюминиевого корпуса.

### 1.3. Исполнение
ESP32 WROOM (Dual Core): ядро 0 — SPI-приёмник (Slave, 18 МГц) с DMA-потоковой передачей в глубокий кольцевой буфер ОЗУ; ядро 1 — Wi-Fi передатчик (Burst streaming) + аппаратный таймер 2-Tone (меандр 125 кГц) для циклической коммутации фазы СВЧ PIN-ключей (38/76 МГц). Питание: Buck-конвертер (5В, шумный), экранированный СВЧ-дроссель BLM18 на границе отсека.

---

## 2. НАЗНАЧЕНИЕ И ЦЕЛИ СОЗДАНИЯ

### 2.1. Назначение
Цифровая передача оцифрованного радиоводопада с базовой полосы (отсек 3, STM32) на ноутбук оператора через Wi-Fi канал. Обеспечение прозрачности данных без слепых зон за счёт глубокого кольцевого буфера ОЗУ.

### 2.2. Цель создания
Максимально быстрая и безопасная доставка потока I/Q-чисел (4.0 MSPS) без потерь, с термостабилизацией акусто-оптического блока (отсек 2) за счёт аппаратной циклической коммутации фаз СВЧ PIN-ключей.

---

## 3. ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ К ИЗДЕЛИЮ

### 3.1. Требования к структуре (поузловой состав)

Отсек 4 должен содержать 4 изолированных узла:

#### Узел 4.1 — Потоковый скоростной приёмник SPI DMA (ядро 0 ESP32)
- Функция: приём непрерывного цифрового потока I/Q-чисел по шине SPI (Slave, 18 МГц) без слепых зон
- Скорость: 4.0 MSPS (микро-секундный поток)
- Память: глубокий кольцевой буфер ОЗУ (асинхронное накопление данных радиоводопада)
- Архитектура: Dual Core ESP32 WROOM, ядро 0 — SPI-приёмник с DMA

#### Узел 4.2 — Асинхронный глубокий кольцевой буфер RAM
- Функция: накопление данных радиоводопада в ОЗУ для последующей передачи
- Тип буфера: кольцевой (FIFO), глубина ≥ 1024 слова (I/Q)
- Запись: от ядра 0 (SPI-приёмник), чтение: ядро 1 (Wi-Fi передатчик)

#### Узел 4.3 — Встроенная печатная змейка-антенна Wi-Fi (ядро 1 ESP32)
- Компоненты: текстолитовая PCB-антенна (змейка), текстолит FR-4
- Направление излучения: строго НАЗАД (излучение заперто в металле алюминиевого корпуса, выходит через радиопрозрачное пластиковое (оргстекло) окно в торце)
- Функция: передача пакетных Burst-вспышек на ноутбук оператора
- Протокол: Wi-Fi (TCP/IP или UDP)

#### Узел 4.4 — Аппаратный таймер 2-Tone (ядро 1 ESP32)
- Функция: генерация меандра частотой 125 кГц (алгоритм 2-Tone) для циклической коммутации фазы СВЧ PIN-ключей (38/76 МГц)
- Цель: термостабилизация оргстекла (отсек 2), блокировка нагрева
- Синхронизация с отсеком 1: TTL импульсы переключения рабочих частот 38 / 76 МГц на PIN-ключи

### 3.2. Требования к электромагнитной совместимости и фильтрации питания

- Питание от Buck-конвертера (шумный цифровой блок): 5В + буферный электролитический конденсатор ≥ 1000 мкФ для гашения Wi-Fi вспышек
- На границе перегородки отсека 4: аппаратно врезан СВЧ-фильтр — дроссель BLM18 (Ferrite Bead) + шунтирующая керамика 10 нФ + 33 пФ для блокировки наводок частотой 2.4 ГГц
- Экранирование отсека: алюминиевая стенка 1.5 мм (Д16Т), изоляция помех ≥ 80 дБ
- Направление Wi-Fi излучения: в органическом (оргстекольном) окне торца корпуса, сквозь радиопрозрачное пластиковое окно наружу
