# REQ-ANA-02 — Пеленгование

**Подсистема:** Расчётные характеристики (не аппаратура)
**Реализация:** `sim/scripts/direction_finding.py` → `out/direction_finding.json`, `out/direction_finding.svg`, `out/df_array.nec`

- **Требование:** Определить зону однозначности и точность пеленгования двухэлементным фазовым интерферометром; обеспечить экспорт геометрии в NEC-2 для AntennaSim.
- **Проверка:** `tests/requirements/reception/test_reception.py::test_doa_*`.

### Сквозной расчёт физики

Двухэлементный базовый интерферометр:

Δφ = 2π · d · sin θ / λ   ⇒   θ = asin(λ · Δφ / 2π · d)

где d — базовое расстояние между элементами, θ — угол прихода,
отсчитываемый от нормали к базе.

**Зона однозначности** ограничена условием |sin θ| ≤ 1:

| база d | зона |备注 |
|---|---|---|
| d = λ/2 (61.2 мм @2.45 ГГц) | ±90° | максимальная, без провалов |
| d = 0.75λ (91.7 мм) | ±41.8° | провалы отсутствуют |
| d = 0.32λ (38.8 мм) | ±18.6° | компромисс точность/зона |

**Точность** пеленга ограничена фазовым шумом:

σ_θ = λ / (2π · d · cos θ) · σ_φ

При d = λ/2, σ_φ = 10°, θ = 35°:
σ_θ = 1 / (2π · 0.82) · 10° ≈ **3.9°**

### Интеграция с AntennaSim

Геометрия экспортируется в формате NEC-2 (`out/df_array.nec`) и может
быть загружена в [AntennaSim](https://github.com/EA1FUO/AntennaSim)
через `POST /api/v1/convert/import`. Прямой запуск `nec2c` в данном
окружении не работает (ошибка разбора геометрии), поэтому при отсутствии
вывода NEC расчёт усиления решётки выполняется аналитически
(аналитический коэффициент направленного действия).

Программный интерфейс: `--antennasim-url` отправляет дек на сервер
`POST /api/v1/simulate`.
