## 3. Діаграма взаємодії блоків (коротко)

```
[0.1]→[0.2]→[0.3]  Антенна система (3 канали)
   ↓     ↓     ↓
  Ant_A  Ant_B  Ant_C  →  GCPW 50 Ом
   ↓     ↓     ↓
[1.1] PIN_Switches (переключач 3→1, REQ-SW1)
   ↓
[1.4] TV_Tuner ←— [1.2] Mixer_1 ←— Канал Б (1.2–3 ГГц)
              ←— [1.3] Mixer_2 ←— Канал В (4.0–7 ГГц)
   ↓
[1.5] KT368_Amp → [1.6] Diode_Clamp → [2.1] Кварц (КТ-1, P≤1 мВт)
                                            ↓
[2.2] PMMA ←— [2.3] Лазер + [2.4] ОУ К140УД7
   ↓ (звук + світло)
[2.5] Нож Фуко → [2.6] Photodiode_IQ (КТ-2, ток 100 нА–600 мкА)
   ↓
[3.1] FPAA_Denoise → [3.2] FPAA_Subtractor → [3.3] STM32_ADC → [3.4] STM32_ML
                                                                    ↓
[4.1] ESP32_DMA → [4.2] ESP32_Buffer → [4.3] ESP32_WiFi → ПК (SDR++)
   ↖__________ [4.4] ESP32_2Tone (зворотний зв'язок на PIN_Switches) __________↙

Питання (зіркова розводка):
[Battery] → [Buck_Converter] → ESP32_DMA (шумні 5В)
[Battery] → [LDO_Analog] → OpAmp_Driver, TV_Tuner, FPAA_Denoise, STM32_ADC (чисті 5В)
[ESP32_DMA] —(навідка СВЧ)→ [5.4] Ferrite_Bead BLM18 → земля
```

## 4. План робіт по кожному блоку

### Блок 0.1: Антенна Канал А (0–900 МГц)
1. Розрахувати геометрію змійки для резонансу на нижній межі діапазону.
2. Спроектувати трасування в KiCad: `block0_5v_bus.kicad_sch`.
3. Розрахувати вхідний опір на 200/400/600/900 МГц (S₁₁ ≤-10 дБ).
4. Узгодити імпеданс з GCPW 50 Ом.
5. Моделювання в NEC2/NEC4: `antenna/band_a/simulation.nec`.

### Блок 0.2: Антенна Канал Б (1.2–3.0 ГГц)
1. Розрахувати розміри патча для 2.45 ГГц.
2. Спроектувати систему живлення 4 елементів (рівномірна фаза і амплітуда).
3. Розрахувати взаємний вплив елементів.
4. Трасування в KiCad: `block1_rf_frontend.kicad_sch`.
5. Моделювання в HFSS/CST або NEC2.

### Блок 0.3: Антенна Канал В (4.0–7.0 ГГц)
1. Розрахувати розміри патча для 5.8 ГГц (врахувати дисперсію, втрати).
2. Спроектувати систему живлення 16 елементів.
3. Розрахувати напрямність (dBi) матриці 4×4.
4. Екранірование: металева камера навколо решітки (алюміній ≥1.5 мм).
5. Трасування в KiCad: `block3.kicad_sch`.
6. Моделювання в HFSS/CST або відкриті альтернативи.

### Блок 1.1: Переключач СВЧ-каналів (PIN-ключі)
1. Відібрати PIN-діоди КА507 для діапазону до 7 ГГц.
2. розрахувати схему комутації 3 входи → 1 вихід.
3. Розрахувати ізоляцію невиділених каналів (≥40 дБ).
4. Забезпечити TTL-керування від ESP32 (Отсек 4).
5. Переконатися, що канали гасяться під час Wi-Fi Burst (REQ-SW1).

### Блоки 1.2–1.6 (СВЧ-тракт)
1. Збірка міксерів на 3А112А, LO 2.0 ГГц і 5.15 ГГц.
2. Настройка ТВ-тюнеру на ПЧ 38 МГц.
3. Буферний каскад КТ368А (ток коллектора 5 мА).
4. Захисна вилка КД522/1N4148 (U_пп ≤0.63 В).
5. Перевірка NF ≤3.5 дБ (REQ-04).

### Блоки 2.1–2.6 (Акустооптична камера)
1. Монтаж кварца 38 МГц, PMMA, лазера, ножу Фуко.
2. Налаштування керування лазером (ОУ К140УД7, 45 мА).
3. Юстировка ножу Фуко (винт М3×0.25, перекриття 50%).
4. Монтаж фотодіодів BPW34 з кроком 0.915 мм.
5. Перевірка стабільності опт. потужності ≤0.5% (REQ-08).

### Блоки 3.1–3.4 (FPAA + STM32)
1. Збірка трансимпедансного каскаду К140УД7.
2. Збірка диференціального вичателю К140УД8 (компенсація 1 мА).
3. Налаштування АЦП STM32 на PA0/PA1 + DMA.
4. Інтеграція TinyML (int8, TensorFlow Lite Micro).

### Блоки 4.1–4.4 (ESP32)
1. Налаштування SPI DMA приймача (Ядро 0).
2. Кільцевий буфер RAM (глибокий).
3. Вбудована PCB-антенна змійка, орієнтація назад (REQ-23).
4. Таймер 2-Tone (Ядро 1, частота ≥125 кГц).
5. Перевірка рівня помехоемісся (CISPR 22 Class B).

### Питання (Блоки 5.1–5.4)
1. Розводка зіркою: Battery → Buck + LDO.
2. Встановлення СВЧ-дросселя BLM18 на кордоні відсеків (REQ-24).
3. Кераміка 10нФ/33пФ на землю біля перегородок.
