# # Блок требования REQ-31

## Низкоуровневое программное обеспечение (Low-level Software)
- **Требование:** Кроссплатформенный драйвер (C/C++, Linux/Windows) для инициализации ПЛИС и непрерывного захвата кадров спектра по шине USB 3.0 без пропусков
- **Структурный блок:** Блок 8 «Программное обеспечение — HOST API»
- **Скрещивание с общими техническими требованиями:**
  - Требование ISO/IEC 25010 (стандарты качества ПО)
  - Совместимость с GNU Radio экосистемой
- **Сквозной расчет физики:** Результаты сквозного физического расчета (Δn ≈ 1.51×10⁻⁵, интенсивность ультразвука I_ac ≈ 18.6 Вт/м², глубина изменения индекса преломления) должны быть доступны через API для интеграции в систему мониторинга в реальном времени. Драйвер должен обеспечивать передачу комплексного потока панорамных данных с частотой считывания ≥50 кHz (строка) и разрешающей способностью пикселя ≥72 дБ. Расчет пикового потока данных: 2048 пикселей × 14 бит × 50 кадров/с = 1.4 Мбит/с, что укладывается в возможности шины USB 3.0 (теоретическая скорость до 5 Гбит/с).
