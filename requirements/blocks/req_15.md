# # Блок требования REQ-15

## Частота считывания строк (Line Readout Frequency)
- **Требование:** Частота считывания строк: не менее 50 кГц
- **Структурный блок:** Блок 3.3 «Тракт ЦОС — Темп считывания»
- **Скрещивание с общими техническими требованиями:**
  - Требование EMVA 1288 Standard
  - Взаимосвязь с ГОСТ 24375-80 / IEEE Std 1664 (шаг частотного разрешения ≤ 250 кГц)
- **Сквозной расчет физики:** При частоте считывания 50 кГц и 2048 пикселях время одного кадра (frame) составляет T_frame = 2048 / 50·10³ ≈ 40.96 ms. Это означает, что прибор может захватывать до 24.4 кадр/second (1/0.04096). Для реального времени панорального мониторинга suffis. Связь с шагом частотного разрешения: при БПЧ 500 МГц и 2048 пикселях шаг на пиксель = 500·10⁶ / 2048 ≈ 244·10³ Гц ≈ 244 кГц, что удовлетворяет требованию ≤ 250 кГц. Частота считывания 50 кГц обеспечивает, что каждый пиксель сканируется с интервалом 20 μs, что достаточно быстро для отслеживания изменений в окружающей радиопробырительной среде (таймеры дронов, радаров PPRCH имеют периоды изменения в миллисекундном диапазоне).
