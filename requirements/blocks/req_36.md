# Блок требования REQ-36

## Отношение сигнал/шум (Signal-to-Noise Ratio, SNR)
- **Требование:** Отношение сигнал/шум на выходе тракта приёма (поток I/Q) — не менее 60 дБ в полосе 2.7 кГц при входном уровне −60 дБм; на пороге обнаружимости S+N/N ≥ 10 дБ.
- **Стандарт:** IEEE Std 1057 / Эквивалент: ITU-R SM.326
- **Структурный блок:** Блок 2 «RF Frontend — отношение сигнал/шум»
- **Скрещивание с общими техническими требованиями:**
  - REQ-04 (коэффициент шума NF ≤ 3.5 дБ) — задаёт нижнюю границу SNR
  - REQ-37 (уровень собственного шума N ≤ −120 дБм) — знаменатель SNR
  - REQ-03 (50 Ом, SMA) — согласование с антенной
  - Полоса измерения 2.7 кГц (SSB) — полоса демодуляции
- **Сквозной расчёт физики:** Определение SNR в полосе B = 2.7 кГц: `SNR = S − N`, где S — мощность сигнала, N — уровень шума (дБ). По REQ-37 уровень собственного шума не превышает N = −120 дБм. Тогда:
  - при S = −60 дБм: SNR = −60 − (−120) = **60 дБ** (выполнение требования);
  - при S = −110 дБм (MDS −110 дБм, сигнал на 10 дБ выше шума): SNR = 10 дБ.

  Проверка через тепловой шум: приведённая ко входу шумовая дорожка k·T·B при T = 290 К и B = 2.7 кГц равна N₀ = −174 дБм/Гц + 10·log₁₀(2700) ≈ −139.7 дБм; с учётом NF ≤ 3.5 дБ (REQ-04) полный шум ≈ −136 дБм. Требование −120 дБм оставляет ≥ 16 дБ запаса на неидеальность тракта и внешнюю помеховую обстановку KB-диапазона.
