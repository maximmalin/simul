# REQ-ANA-03 — Распознавание сигналов (YOLO)

**Подсистема:** Программная обработка
**Реализация:** `ml/` — `spectrogram.py`, `scene.py`, `dataset.py`, `detector.py`, `train.py`

- **Требование:** Автоматическое распознавание типа модуляции сигналов на водопаде с выдачей координат и класса.
- **Классы:** `cw` (несущая), `am` (АМ), `fm` (ЧМ), `noise` (шумовой источник)
- **Проверка:** `ml_data/data.yaml`, `tests/requirements/ml/`.

### Сквозной расчёт физики

Входной сигнал — комплексная огибающая I/Q. Преобразование в изображение
для детектора выполняется через STFT:

| параметр | значение | обоснование |
|---|---|---|
| размер БПФ | 128 отсчётов | соответствует 128 строкам изображения |
| перекрытие | 50 % (hop = 64) | стандартное для STFT |
| полоса обустройства fs | 250 кГц | разрешение боковых полос АМ/ЧМ |
| разрешение по частоте | fs/N = 1.95 кГц | АМ с БМ 4–14 кГц разрешается |

Выбор fs = 250 кГц обусловлен тем, что при большей частоте дискретизации
боковые полосы АМ (2·f_мод) не разрешаются окном в 128 отсчётов и АМ
неотличима от несущей.

### Разметка

Истинные рамки вычисляются аналитически из параметров источника:

| класс | занимаемая полоса |
|---|---|
| `cw` | 3·δf (линия) |
| `am` | 2·f_мод |
| `fm` | 2·(Δf + f_мод) — правило Карсона |
| `noise` | заданная полоса |

Датасет синтезируется из физической модели эфира
(`ml/scene.py`), поэтому разметка не требует ручной работы.
Формат совместим с YOLO: `<class> cx cy w h` в нормализованных координатах.

### Модель

Компактная YOLO-сетка (Keras/TensorFlow): свёрточное ядро 16→32→64
со снижением разрешения до сетки 16×16, один якорь на ячейку,
декодирование с NMS. Разрешение 128×128, один канал.

Если TensorFlow недоступен, работает numpy-детектор на основе
спектральных пиков (`ml/detector.py:numpy_detect`).
