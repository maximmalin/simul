# REQ-ANT-03 — Антенная система, канал C

- **Требование:** Приём в диапазоне 4.0–7.0 ГГц, резонанс 5.8 ± 0.05 ГГц, КНД ≥ 12 дБи, входное сопротивление 50 ± 5 Ом, боковые лепестки ≤ −15 дБ.
- **Проверка:** `tests/requirements/antenna/test_antenna.py`; NEC-2 / AntennaSim.

### Сквозной расчёт физики

Решётка 4×4 на FR-4. Для резонанса 5.8 ГГц λ_0 = 51.7 мм,
размер элемента ≈ 13.8 мм с учётом ε_r = 4.4 и краевых эффектов.

Шаг решётки ≈ 0.4·λ_0 = 20.7 мм — при таком заполнении боковые
лепестки удерживаются ниже −15 дБ.

КНД: +6.5 дБи (элемент) + 6.2 дБи (усиление 4×4) ≈ **12.7 дБи**.

Диапазон 4.0–7.0 ГГц перекрывается одним элементом с КСВН ≤ 2
в пределах ±20 % от резонанса.
