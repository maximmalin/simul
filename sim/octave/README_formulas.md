# Модуль 1 «Ячейка Брэгга» — формулы и параметры (Octave)

Папка `sim/octave/` содержит формулы, по которым считаются выходные параметры
блока, и аналитическую самопроверку FEM-решения.

## Какие параметры вычисляются

Вход модели (задаёт пользователь):

| Параметр | Символ | Ед. |
|---|---|---|
| Длина блока | `Lx` | м |
| Ширина блока | `Ly` | м |
| Высота стекла | `H_g` | м |
| Толщина кварца | `H_q` | м |
| Сетка | `h` | м |
| Плотность/`E`/`ν` стекла | `ρ_g, E_g, ν_g` | кг/м³, Па, — |
| Плотность/`E`/`ν` кварца | `ρ_q, E_q, ν_q` | кг/м³, Па, — |
| Объёмная сила на кварце | `b1, b2, b3` | Н/м³ |
| Фотоупругий коэффициент | `C = dn_scale_quartz` | — |

Выход модели (ФEM-решатель + пост-обработка):

| Параметр | Формула | Ед. |
|---|---|---|
| Поле перемещений | решение `div σ + b = 0` | м |
| `displacement_max` | `max_x \|u(x)\|` | м |
| Компоненты напряжения | `σ_xx, σ_yy, σ_zz` (StressSolve) | Па |
| `eps_zz` (кварц) | `ε_zz = (σ_zz − ν_q(σ_xx + σ_yy)) / E_q` | — |
| `delta_n` (кварц) | `Δn = C · ε_zz` | — |
| `model_status` / `accuracy_metadata` | служебные | — |

Закон Гука (обратный): `σ = C : ε`, `ε = ½(∇u + ∇uᵀ)`.

## Аналитическая самопроверка (стержневая модель)

Кварцевый слой при нагрузке `b1` по оси X ведёт себя как консольный брус:

```
w = b1 · Ly · H_q                    [Н/м]  — погонная нагрузка
A = Ly · H_q                          [м²]  — площадь сечения
σ_xx(x) = w·(Lx − x)/A = b1·(Lx − x) [Па]  — растёт к заделке
u_max   = b1·Lx² / (2·E_q)            [м]   — перемещение конца
```

При значениях по умолчанию: `σ_xx,max = b1·Lx = 6.75e-5 Па`,
`u_max = 6.449e-18 м`. FEM даёт `displacement_max = 6.430e-18 м` — совпадение
`~0.3%`, модель корректна.

## Связь с FMU

`engine_mode = 0` (linearized) вычисляет те же выходы алгебраически: при
инициализации решаются 3 опорных случая `b = e₁, e₂, e₃`, затем для произвольной
нагрузки `b` используется линейность упругой задачи:

```
u(b)      = Σᵢ bᵢ · u(eᵢ)
ε_zz(b)   = Σᵢ bᵢ · ε_zz(eᵢ)
Δn(b)     = C · ε_zz(b)
displacement_max(b) = Σᵢ |bᵢ| · max|u(eᵢ)|    (верхняя оценка)
```

`engine_mode = 1` (full) каждый шаг решает полную FEM-задачу.

## Надёжность (Krystal Radio, SDR)

`reliability_model.m` — модель parts-count с температурным ускорением по
Аррениусу. Проверяет **REQ-26** (MTBF ≥ 10 000 ч) по данным даташитов из
`reliability_parts.tsv` (base FIT, Ea, T_ref/T_use, π_Q).

```bash
octave --quiet --eval "addpath('sim/octave'); \
    reliability_model('sim/octave/reliability_parts.tsv','out/reliability.json')"
# или просто: make reliability
```

Тесты: `tests/requirements/reliability/`.
