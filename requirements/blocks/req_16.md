# # Блок требования REQ-16

## Рабочий диапазон температур (Operating Temperature Range)
- **Требование:** +15° C до +30° C
- **Структурный блок:** Блок 4.1 «Климатические условия — Температура»
- **Скрещивание с общими техническими требованиями:**
  - Требование ГОСТ 15150-69 (Испытания климатические)
  - Эквивалент: ISO 554-1976 (метод температурных испытаний)
- **Сквозной расчет физики:** Температурный дрейф шкалы частот должен удерживаться в пределах ±250 кГц. При рабочей температуре +15...+30° C без системы стабилизации дрейф частоты может достигать several MHz из-за температурного расширения сплава Д16Т (α ≈ 23×10⁻⁶ /°C) и температурной зависимости показателя réfractive index кристалла TeO₂ (dn/dT ≈ 1.5×10⁻⁵ /°C). Система стабилизации на элементах Пельтье с точностью ±0.1° C удерживает дрейф в пределах требований. При ±0.1° C ошибки дрейф частоты Δf/f ≈ (dn/dT + α) · ΔT · f_central ≈ (1.5×10⁻⁵ + 23×10⁻⁶) · 0.1 · 38·10⁶ ≈ 125 кГц, что укладывается в ±250 кГц. Это подтверждает, что система термостабилизации является критически важным требованием для поддержания точности измерений.
