# # Блок требования REQ-19

## Активная система термостабилизации (Active Thermal Stabilization)
- **Требование:** Конструкция должна содержать активную систему термостабилизации лазерного диода и АО-ячейки на базе элементов Пельтье с точностью удержания температуры ± 0.1° C
- **Структурный блок:** Блок 4.3 «Система стабилизации температуры»
- **Скрещивание с общими техническими требованиями:**
  - Требование ГОСТ 15150-69 (климатическое исполнение УХЛ4)
  - Соответствие ГОСТ 30804.4.3-2013 (иммунность к внешним полям)
- **Сквозной расчет физики:** Элементы Петелье (TEC) с точностью ±0.1° C критически важны для поддержания стабильности Δn ≈ 1.51×10⁻⁵. Без стабилизации дрейф Δn может достигать 20–30% от nom value при изменении температуры на 1° C (dn/dTeO₂ ≈ 1.5×10⁻⁵ /°C). Система Петелье с двумя сенсорами температуры (лазерный диаод + кристалл) и ПИД-регулятором обеспечивает удержание температуры в пределах ±0.1° C, что соответствует требованию о dither_freq ±250 кГц. Расход энергии системы: ~2–5 Вт от батарейного питания (раздел 3.3). ПИД-регулятор реализуется на ПЛИС с использованием датчиков температуры MAX6605 (точность ±0.5° C) для обратной связи и драйверов TEC1265 для питания элементов Петелье.
