# REQ-RF-01 — Вход ВЧ-тракта

**Подсистема:** ВЧ (радиочастотная часть)
**Аппаратная реализация:** `J_ANT` (SMA_EDGE), `R_TERM` 50 Ом, `TP_ANT`

- **Требование:** Вход ВЧ-тракта — коаксиальный разъём SMA с входным сопротивлением 50 ± 2 Ом во всём диапазоне 0–7 ГГц.
- **Стандарт:** ГОСТ 20275-91 (коаксиальные соединители), IEC 61169-4-17 (SMA).
- **Проверка:** `tests/requirements/rf/`, `sim/scripts/sdr_skidl_circuit.py` → нетлист; измерение S₁₁ на `TP_ANT`.

### Сквозной расчёт физики

R_TERM = 50 Ом задаёт входное сопротивление нагрузки. Рассогласование
разъёма и печатной платы ограничивает КСВН: при |S₁₁| ≤ −18 дБ отражённая
мощность составляет не более 1.6 % падающей, то есть потери на рассогласовании
не превышают 0.07 дБ на проход.

Контрольная точка `TP_ANT` выведена на плату для измерения входного импеданса
и разделения каналов при стыковке с антенной.
