# REQ-IO-01 — Передача данных на компьютер

**Подсистема:** Интерфейс с ПК
**Аппаратная реализация:** `J_USB` (USB_B, CDC), `R_USB1`/`R_USB2` 22 Ом

- **Требование:** Передача комплексного потока I/Q на компьютер по USB без пропуска кадров при заданной частоте дискретизации.
- **Стандарт:** USB 2.0 Full-Speed, класс CDC.
- **Проверка:** `src/gnuradio_krystal/`, `make gnuradio` → `out/virtual_rx_spectrum.json`.

### Сквозной расчёт физики

Резисторы `R_USB1`/`R_USB2` = 22 Ом — стандартная последовательная
терминация USB-пары, требование спецификации USB 2.0 §5.3.4
(d series termination).

Полоса CDC на Full-Speed ограничена пакетной передачей: один микрокадр
(125 мкс) при максимальном размере пакета 64 байта даёт
64 / 125·10⁻⁶ = 512·10³ байт/с. Для complex float32 (8 байт на отсчёт)
это 64·10³ отсчётов/с суммарно по двум каналам.

> **Известное ограничение первой ревизии.** Полоса USB CDC Full-Speed
> (~64 KSPS на канал) **ниже** частоты выборки АЦП (REQ-BB-02, до 1 MSPS).
> Передача в реальном времени на полной частоте выборки невозможна —
> доступен только буферизованный режим с потерями.
> Для потоковой работы на высоких частотах необходим USB High-Speed
> или внешний интерфейс (Ethernet/SPI).
