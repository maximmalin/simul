# tests/requirements/antenna/
Тесты антенной системы Brig Receiver по матрице требований (REQ-A1, REQ-B1, REQ-C1, REQ-SW1, REQ-ANT-ALL).

## Что тестируется
- REQ-A1: канал А 0–900 МГц, импеданс 50±10 Ом, КНД ≥5 дБи на 433 МГц, SWR≤2.0, FR-4 0.8 мм, GCPW 50 Ом (W=1.2 мм, зазор=0.2 мм), панель 150×150 мм
- REQ-B1: канал Б 1.2–3.0 ГГц, резонанс 2.45±0.02 ГГц, импеданс 50±5 Ом, КНД ≥8 дБи, SWR≤1.5, матрица 2×2, шаг 91.7 мм, FR-4 0.8 мм
- REQ-C1: канал В 4.0–7.0 ГГц, резонанс 5.8±0.05 ГГц, импеданс 50±5 Ом, КНД ≥12 дБи, SWR≤2.0, матрица 4×4, уровень боковых лепестков ≤-15 дБ, экранирование алюминий ≥1.5 мм, FR-4 0.8 мм (для ≥5 ГГц — Rogers RO4350B допускается)
- REQ-SW1: переключатель PIN-ключи КА507, 3→1, изоляция невыбранных ≥40 дБ, время переключения ≤1 мкс, TTL от ESP32, гашение во время Wi-Fi Burst
- REQ-ANT-ALL: комплекс — три канала на одной панели 150×150 мм, FR-4 0.8 мм, полное покрытие 0–7 ГГц без пропусков, переключение без потери КНД, файлы трассировки block0_5v_bus.kicad_sch, block1_rf_frontend.kicad_sch, block3.kicad_sch

## Как запускать
.venv/bin/pytest tests/requirements/antenna/ -v
