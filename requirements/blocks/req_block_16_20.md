# Блок требований: Климатические и механические условия — Часть 2

## Ссылка на требование: REQ-16 через REQ-20

### 16. Рабочий диапазон температур (Operating Temperature Range)
- **Требование:** +15° C до +30° C
- **Структурный блок:** Блок 4.1 «Климатические условия — Температура»
- **Скрещивание с общими техническими требованиями:**
  - Требование ГОСТ 15150-69 (Испытания климатические)
  - Эквивалент: ISO 554-1976 (метод температурных испытаний)
- **Сквозной расчет физики:** Температурный дрейф шкалы частот должен удерживаться в пределах ±250 кГц. При рабочей температуре +15...+30° C без системы стабилизации дрейф частоты может достигать several MHz из-за температурного расширения сплава Д16Т (α ≈ 23×10⁻⁶ /°C) и температурной зависимости показателя réfractive index кристалла TeO₂ (dn/dT ≈ 1.5×10⁻⁵ /°C). Система стабилизации на элементах Пельтье с точностью ±0.1° C удерживает дрейф в пределах требований. При ±0.1° C ошибки дрейф частоты Δf/f ≈ (dn/dT + α) · ΔT · f_central ≈ (1.5×10⁻⁵ + 23×10⁻⁶) · 0.1 · 38·10⁶ ≈ 125 кГц, что укладывается в ±250 кГц.

### 17. Предельный диапазон температур (Extreme Temperature Range)
- **Требование:** от -40° C до +50° C (в выключенном состоянии)
- **Структурный блок:** Блок 4.1 «Климатические условия — Экстремальные температуры»
- **Скрещивание с общими техническими требованиями:**
  - Требование ГОСТ 15150-69, Класс 3K3 / 3M1
  - Эквивалент: IEC 60721-3-3
- **Сквозной расчет физики:** В диапазоне -40...+50° C материальные свойства могут измениться: коэффициент температурного расширения сплава Д16Т изменяется от 17×10⁻⁶ /°C при -40° C до 29×10⁻⁶ /°C при +50° C. Это может привести к механическому перекосу оптической оси на 0.5–1.0 μm. Допуск 0.5 μm при максимальной рабочей температуре (см. требование REQ-22) задается с учетом этих изменений. Элементы Пельтье должны работать в rozsширенном диапазоне без потери эффективности конвертации энергии.

### 18. Относительная влажность (Relative Humidity)
- **Требование:** не более 80% при температуре +25° C (без конденсации влаги)
- **Структурный блок:** Блок 4.2 «Климатические условия — Влажность»
- **Скрещивание с общими техническими требованиями:**
  - Требование ГОСТ 15150-69
  - Эквивалент: ISO 554-1976 (влажность)
- **Сквозной расчет физики:** При относительной влажности >80% при +25° C возможно образование конденсата на поверхности кристалла TeO₂ и фотодиодов.Конденсат изменяет показатель преломления на поверхности кристалла, что приводит к неконтролируемому изменению Δn и искажению дифракционного пика. Внутри корпуса должен быть заложен расчетное количество активированного силикагеля (по ГОСТ 3956-76) для поглощения излишков влаги. Расчетный вес силикагеля: m_silica ≈ 5–10 г для объема корпуса ~500 см³, срок службы до полной насыщенности (3 года без переконсервации per ГОСТ 9.014-78).

### 19. Активная система термостабилизации (Active Thermal Stabilization)
- **Требование:** Конструкция должна содержать активную систему термостабилизации лазерного диода и АО-ячейки на базе элементов Пельтье с точностью удержания температуры ± 0.1° C
- **Структурный блок:** Блок 4.3 «Система стабилизации температуры»
- **Скрещивание с общими техническими требованиями:**
  - Требование ГОСТ 15150-69 (климатическое исполнение УХЛ4)
  - Соответствие ГОСТ 30804.4.3-2013 (иммунность к внешним полям)
- **Сквозной расчет физики:** Элементы Пельтье (TEC) с точностью ±0.1° C критически важны для поддержания стабильности Δn ≈ 1.51×10⁻⁵. Без стабилизации дрейф Δn может достигать 20–30% от nom value при изменении температуры на 1° C (dn/dTeO₂ ≈ 1.5×10⁻⁵ /°C). Система Пельтье с двумя сенсорами температуры (лазерный диаод + кристалл) и ПИД-регулятором обеспечивает удержание температуры в пределах ±0.1° C, что соответствует требованию о dither_freq ±250 кГц. Расход энергии системы: ~2–5 Вт от батарейного питания (раздел 3.3).

### 20. Устойчивость к вибрации (Vibration Resistance)
- **Требование:** Конструкция должна uwithstand вибрационным нагрузкам в диапазоне частот 10–55 Гц с амплитудой смещения до 0.15 мм
- **Структурный блок:** Блок 4.4 «Механическая прочность — Вибрация»
- **Скрещивание с общими техническими требованиями:**
  - Требование ГОСТ 30631-99 (ИКЦ 60068-2-6)
  - Эквивалент: IEC 60068-2-6 (синусоидальный метод)
- **Сквозной расчет физики:** Вибрационные нагрузки на частотной ranges 10–55 Гц с амплитудой 0.15 мм могут вызывать модуляцию оптического пути с частотой модуляции f_mod ≈ v_amplitude · / λ ≈ 0.15 mm / 650 nm ≈ 230 kHz. Это может привести к фазовым флуктуациям в дифракционном пике. Фирмная монтаж элементов оптической схемы на едином фрезерованном основании из сплава Д16Т (Al 2024-T3) с жестким креплением минимизирует передачу вибраций к кристаллу TeO₂. Допуск на пространственный перекос элементов оптической оси при максимальной рабочей температуре не должен превышать 0.5 μm (требование REQ-22), что обеспечено использованием вибропрочного компенсатора из эластичного полимера с модулем упругости E ≈ 2 GPa.
