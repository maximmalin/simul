# # Блок требования REQ-06

## Выходной ВЧ-драйвер (RF Output Driver)
- **Требование:** Линейный усилитель мощности сигнала до 1.5 Вт для обеспечения максимальной дифракционной эффективности пьезоэлектрического преобразователя ячейки Брэгга
- **Структурный блок:** Блок 4 «RF Frontend — Выходной тракт»
- **Скрещивание с общими техническими требованиями:**
  - Требление GOST IEC 60825-1 Class 3B (безопасность лазера)
  - Соответствие ГОСТ 30804.4.3-2013 (иммунность к внешним полям)
- **Сквозной расчет физики:** Каскад усиления ТВ-селектора + УПЧ КТ368А: G_tuner ≈ 25 дБ = 316, G_KT368 ≈ 18 дБ = 63, итоговая полная электрическая мощность на выходе: P_rf_out = (1.56×10⁻⁷ Вт) × 316 × 63 = 0.0031 Вт = 3.1 мВт (+4.9 дБм). Данная мощность укладывается в расчетный предел безопасности ≤10 мВт, выведенный ранее для исключения насыщения лазерного луча. Мощность 1.5 Вт на выходе драйвера обеспечивает максимальную дифракционную эффективность, так как не превышает порог насыщения фазового шума < -110 дБс/Гц, задаваемый ножом Фуко. При мощности >1.5 Вт интенсивность ультразвука I_ac превысит значение 18.6 Вт/м², что приведет к перегрузке кристалла TeO₂ и искажению дифракционного пика (гиперболический рост η_opt при больших I_ac).
