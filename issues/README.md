# issues/
Папка для файлов задач (issues) Brig Receiver.

## Структура
- `issues/` — файлы задач в формате Markdown
- Каждая задача — отдельный файл `issue_<N>.md`
- Задачи могут быть связаны с требованиями, тестами, расчётами

## Пример
- `issue_antenna_swr.md` — задача по SWR для антенной системы
- `issue_rf_nf.md` — задача по NF для RF Frontend
- `issue_ao_stability.md` — задача по стабильности оптической мощности

## Связь с требованиями
- Каждая задача может ссылаться на требование (req_id): REQ-A1, REQ-04, REQ-11 и т.д.
- Задачи могут быть созданы на основе чек-листа tests/requirements/checklist.csv

## Пример содержания
```
# Задача: улучшить SWR для антенны Канал А

## Требование
REQ-A1: SWR ≤ 2.0 по полосе 0–900 МГц

## Описание
Текущий дизайн змейки имеет SWR > 2.0 на частотах 300–400 МГц.
Необходимо оптимизировать геометрию змейки для достижения SWR ≤ 2.0.

## Действия
1. Рассчитать геометрию змейки для 300–400 МГц
2. Сделать симуляцию в NEC2/NEC4
3. Обновить файл simulation.nec
4. Проверить SWR после изменений

## Владение
- Автор: ...
- Статус: открыта
```
