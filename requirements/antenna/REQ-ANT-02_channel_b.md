# REQ-ANT-02 — Антенная система, канал B

- **Требование:** Приём в диапазоне 1.2–3.0 ГГц, резонанс 2.45 ± 0.02 ГГц, КНД ≥ 8 дБи, входное сопротивление 50 ± 5 Ом (КСВН ≤ 1.5), шаг элементов 91.7 мм.
- **Проверка:** `tests/requirements/antenna/test_antenna.py`; NEC-2 / AntennaSim.

### Сквозной расчёт физики

Микрополосковая антенна 2×2 на FR-4 (ε_r = 4.4, h = 0.8 мм).
Для резонанса 2.45 ГГц: λ_0 = 122.4 мм, эффективная длина в
диэлектрике λ_eff ≈ 82 мм, размер элемента с учётом краевых эффектов:

l ≈ λ_eff/2 − 2Δl ≈ 41 − 8 = **33 мм**

Шаг сетки 2×2: 91.7 мм ≈ 0.75·λ_0 — компромисс между
направленностью и взаимным влиянием элементов.

КНД решётки 2×2: +5.5 дБи (одиночный элемент) + 3.5 дБи (усиление
решётки) ≈ **9 дБи**.
