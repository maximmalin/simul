# # Блок требования REQ-17

## Предельный диапазон температур (Extreme Temperature Range)
- **Требование:** от -40° C до +50° C (в выключенном состоянии)
- **Структурный блок:** Блок 4.1 «Климатические условия — Экстремальные температуры»
- **Скрещивание с общими техническими требованиями:**
  - Требование ГОСТ 15150-69, Класс 3K3 / 3M1
  - Эквивалент: IEC 60721-3-3
- **Сквозной расчет физики:** В диапазоне -40...+50° C материальные свойства могут измениться: коэффициент температурного расширения сплава Д16Т изменяется от 17×10⁻⁶ /°C при -40° C до 29×10⁻⁶ /°C при +50° C. Это может привести к механическому перекосу оптической оси на 0.5–1.0 μm. Допуск 0.5 μm при максимальной рабочей температуре (см. требование REQ-22) задается с учетом этих изменений. Элементы Пельтье должны работать в rozsended диапазоне без потери эффективности конвертации энергии. При температурах ниже -20° C эффективность элементов Пельтье уменьшается на ~20% из-за повышения внутреннего сопротивления, но при -40° C все еще обеспечивает стабильность ±0.2° C при сниженной нагрузке. При температурах выше +40° C выходной ток Пельтье уменьшается, требуя перерасчета коэффициентов ПИД-регулятора.
