# REQ-PERF-02 — Отношение сигнал/шум и чувствительность

**Подсистема:** Основные характеристики · **Связано с:** REQ-RF-02, REQ-BB-01

- **Требование:** NF тракта ≤ 3.5 дБ; шумовая дорожка и минимально детектируемый сигнал (MDS) в полосе ПЧ 2.7 кГц.
- **Стандарт:** IEEE Std 145.
- **Проверка:** `sim/scripts/link_budget.py` → `out/link_budget.json`; `tests/requirements/reception/`.

### Сквозной расчёт физики

Каскадное сложение NF по Friis (см. REQ-RF-02) даёт NF_total ≈ 2.14 дБ.
Для соблюдения базовой нормы NF = 3.5 дБ (REQ-RF-02) шумовая дорожка
в полосе ПЧ B = 2.7 кГц:

N = k·T·B · F,  k = 1.38·10⁻²³ Дж/К, T = 290 К, F = 10^(3.5/10) = 2.24

N = 1.38·10⁻²³ · 290 · 2700 · 2.24 = **2.42·10⁻¹⁵ Вт = −136.2 дБм**

MDS при SNR = 10 дБ (для SSB-детектирования):
S_min = −136.2 + 10 = **−126.2 дБм**

> **Значения зафиксированы** в `out/link_budget.json` и проверяются тестами
> `tests/requirements/reception/test_reception.py`.

### Динамический диапазон

Отношение перегрузки (по перехвату смесителя, P1dB ≈ +10 дБм) к MDS:
DR = +10 − (−126.2) = **136 дБ** теоретически; реально ограничено
SFDR тракта (REQ-PERF-03).
