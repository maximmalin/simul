# ПАКЕТ ДОКУМЕНТОВ

Plan-папка (planned): plan/

Plan-папка (structured by blocks): plan/blocks.md

Plan-папка (readme): plan/README.md

Plan-папка (checks script): plan/checks.py

Это Plan-папка.
В папке plan лежат:
- plan.md — план робіт (короткий)
- blocks.md — план блоків (довгий, детальний)
- README.md — читай це, якщо треба зрозуміти структуру
- checks.py — скрипт для перевірки готовності

Структура plan/blocks.md:
1. Увод
2. Блоки системи (список блоків з описом, входами, виходами)
3. Критерії прийому (для кожного блоку)
4. Діаграма взаємодії блоків (за схемою structural.drawio)
5. План робіт по кожному блоку (крок за кроком)
6. Посилання на ТЗ (окремі файли в work/tz-*)

Кожен блок має своє ТЗ в work/tz-*:
- work/tz-a/ — Блок 0: Система живлення 5В
- work/tz-b/ — Блок 1: СВЧ-тракт і селекція
- work/tz-c/ — Блок 2: Акусто-оптична камера
- work/tz-d/ — Блок 3: ФПАА і Сопроцесор STM32
- work/tz-e/ — Блок 4: Цифровий канал зв'язку ESP32

Подивися blocks.md — там описано всі блоки, їхні входи/виходи, критерії прийому і детальний план крока за кроком.

Детальніше в work/tz-* — там окремі файли з повним техзаданням для кожного блоку.
