# # Блок требования REQ-07

## Длина волны лазера (Laser Diode Wavelength)
- **Требование:** Полупроводниковый лазерный диод с длиной волны λ = 650 нм (или 532 нм)
- **Структурный блок:** Блок 3 «АО-процессор — Источник излучения»
- **Скрещивание с общими техническими требованиями:**
  - Требование диапазона частот: 10 МГц–6 ГГц (общий диапазон приема)
  - Соответствие ГОСТ 30804.4.3-2013 (иммунность к внешним полям)
- **Сквозной расчет физики:** Длина волны λ = 650 нм выбрана оптимально для кристалла TeO₂ (поволновая интервал ≈ 71.05 μm), обеспечивая дифракцию на управляемом угле. Условие дифракции Брэгга: 2·d·sin(θ) = m·λ, где d = 71.05 μm — период звуковой решетки кристалла TeO₂, θ — угол дифракции. При λ = 650 нм и нормальной incidence (θ ≈ 0): дифракционный угол определяется отношением λ/d = 650·10⁻⁹ / 71.05·10⁻⁶ ≈ 0.00915 рад. Выбранная длина волны обеспечивает удобный геометрическийRatio для фотодиодов на расстоянии 4.3 мм от оси центрального луча: Δx = L_arm · tan(λ/Λ) = 100 мм · tan(0.00915 рад) ≈ 0.915 мм. При λ = 532 нm дифракционный угол был бы smaller (λ/Λ ≈ 0.0075 рад), требующий большей дистанции между фотодиодами. Выбор λ = 650 nm позволил реализовать компактную геометрию с шагом 4.3 мм (с учетом коэффициента перекрестной дифракции и аподизации).
