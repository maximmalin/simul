# Блок-узел 0.2: Микрополосковая решётка 2×2 (1.2–3.0 ГГц, настройка 2.45 ГГц)

## Общие данные
- Тип антенны: Микрополосковая патч-антенна, матрица 2×2
- Частотный диапазон: 1.2–3.0 ГГц
- Настройка (основная): 2.45 ГГц (перехват БПЛА и Wi-Fi 2.4)
- Материал: СВЧ-текстолит FR-4, толщина 0.8 мм, ε = 4.5
- Шаг между центрами элементов: 91.7 мм
- Связь с трактом: GCPW 50 Ом (ширина 1.2 мм, зазор 0.2 мм)
- Количество элементов: 4 (2×2)

## Технические задания
1. Рассчитать размеры отдельного патча для резонансной частоты 2.45 ГГц:
   - Длина патча ≈ λ₀ / (2√ε_eff), где ε_eff — эффективная диэлектрическая проницаемость микрополосковой линии
   - Ширина патча определяется по формуле для микрополосковой антенны
2. Спроектировать систему питания 4 элементов:
   - Распределительная сеть с равномерной фазой и амплитудой
   - Тип питания: микрополосковая линия с щелевым или контактным возбуждением
3. Рассчитать взаимное влияние элементов (коррелированное возбуждение, частота резонанса при наличии соседей).
4. Рассчитать угол сканирования луча в зависимости от фазы питания.
5. Создать трассировку в KiCad / Altium — файл `block1_rf_frontend.kicad_sch`.
6. Провести моделирование в HFSS/CST или открытой альтернативе (NEC2 с модификациями для микрополосковых структур).
7. Свести результаты с экспериментом.

## Критерии приемки
- Резонансная частота: 2.45 ± 0.02 ГГц
- КНД (усиление): не менее 8 дBi (в основном лепестке)
- Входное сопротивление: 50 ± 5 Ом (SWR ≤ 1.5)
- Матрица 2×2, шаг 91.7 мм, панель 150 × 150 мм

## Файлы
