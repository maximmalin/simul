# Brig Receiver — экспорт геометрии антенн (FreeCAD / STEP / STL)

Три печатные антенны на панелях **150 × 150 мм**, FR-4 **0.8 мм**, медь **0.035 мм**
(εr = 4.5, tanδ = 0.02).

## Файлы

| Файл | Канал | Описание |
|------|-------|----------|
| `band_a.step` / `.stl` | A | Змейка 200 МГц — 3 плеча по 63.5 мм, шаг 15 мм, дорожка 1.2 мм |
| `band_b.step` / `.stl` | B | Решётка 2×2 @ 2.45 ГГц — патч 36.89 × 28.35 мм, шаг 91.7 мм |
| `band_c.step` / `.stl` | C | Решётка 4×4 @ 5.8 ГГц — патч 15.59 × 11.62 мм, шаг 38.77 мм |
| `build_brig_antennas_fc.py` | — | Макрос FreeCAD: строит и экспортирует всё заново |

Состав каждой модели: нижняя медь (земля), подложка FR-4, верхняя медь (излучатели/дорожки).

## Размеры

Панель: 150 × 150 × 0.87 мм (FR-4 0.8 + медь 0.035 сверху/снизу).
Толщина меди/εr/тангенс — как в симуляции (`sim/scripts/antenna_sim.py`).

### Канал A — змейка (200 МГц)
- 3 горизонтальных плеча длиной 63.5 мм, шаг 15 мм, ширина дорожки 1.2 мм
- Запитка: линия от нижнего плеча к нижнему краю панели (GCPW-переход)
- Резонанс — аналитическая четвертьволновая оценка (FDTD на 200 МГц непрактичен)

### Канал B — решётка 2×2 (2.45 ГГц)
- Элемент: W = 36.89 мм, **L = 28.35 мм** (подстроено FDTD, резонанс 2.45 ГГц)
- Смещение зонда питания от центра элемента: **−8.88 мм** (по −y; ~50 Ом)
- Расстояние между центрами: 91.7 мм
- Центры элементов: 29.15 / 120.85 мм от края (симметрично)

### Канал C — решётка 4×4 (5.8 ГГц)
- Элемент: W = 15.59 мм, **L = 11.62 мм** (подстроено FDTD, резонанс 5.8 ГГц)
- Смещение зонда питания от центра элемента: **−2.62 мм** (по −y; ~50 Ом)
- Расстояние между центрами: 38.77 мм
- Центры элементов: 16.85 / 55.62 / 94.39 / 133.15 мм от края

## Как открыть / пересобрать

**Открыть готовое:** импортируйте `*.step` в FreeCAD (File → Open), либо `*.stl`.

**Пересобрать из макроса:**
```bash
freecadcmd hardware/antenna/geometry/build_brig_antennas_fc.py
```
Скрипт создаст все 6 файлов заново в этой папке.

## Примечания
- Топология (координаты элементов) и **подстроенные длины патчей / смещения
  зондов** согласованы с ЭМ-моделью `sim/scripts/radiation.py`
  (`sim/outputs/openems_results.json` → `geometry`).
- Геометрия — для механической компоновки и подготовки к трассировке в KiCad/Altium.
  Согласующая сеть питания (корпоративный делитель) в 3D-модель не входит.
