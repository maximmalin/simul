# tests/requirements/rf/
Тесты RF Frontend по матрице требований (REQ-01, REQ-03, REQ-04, REQ-05, REQ-06).

## Что тестируется
- REQ-01: мгновенная полоса частот не менее 500 МГц (целевая 1000 МГц), покрытие 0–7 ГГц
- REQ-03: входное сопротивление 50 Ом, разъём SMA (ГОСТ 20275-91), VSWR<1.5 в диапазоне 0–7 ГГц
- REQ-04: коэффициент шума входного тракта NF ≤ 3.5 дБ (IEEE Std 145), чувствительность -110 дБм
- REQ-05: защита от перегрузки до +20 дБм, преселекторы, малошумящий усилитель
- REQ-06: выходной ВЧ-драйвер — линейный усилитель до 1.5 Вт, максимальная дифракционная эффективность

## Как запускать
.venv/bin/pytest tests/requirements/rf/ -v
