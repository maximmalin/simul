# Блок-узел 0.3: Микрополосковая матрица патчей 4×4 (4.0–7.0 ГГц, настройка 5.8 ГГц)

## Общие данные
- Тип антенны: Микрополосковая матрица патчей, массив 4×4 (16 элементов)
- Частотный диапазон: 4.0–7.0 ГГц
- Настройка (основная): 5.8 ГГц (СВЧ-РЭБ, Wi-Fi 5/5.8 ГГц)
- Материал: СВЧ-текстолит FR-4, толщина 0.8 мм, ε = 4.5
  - Примечание: для верхней части диапазона (выше 5 ГГц) рекомендуется 고려ать Rogers RO4350B или аналог для снижения потерь
- Связь с трактом: GCPW 50 Ом (ширина 1.2 мм, зазор 0.2 мм)
- Количество элементов: 16 (матрица 4×4)
- Панель: 150 × 150 мм (вмещает матрицу с границами)

## Технические задания
1. Рассчитать размеры отдельного патча для 5.8 ГГц:
   - Учесть высокочастотные эффекты (дисперсия, потери в срезах, поверхностное сопротивление)
   - При необходимости использовать эффективную диэлектрическую проницаемость с учетом тонкой подложки
2. Спроектировать систему питания 16 элементов:
   - Распределительная сеть (волновая или резистивная) с контролем фазы и амплитуды
   - Симметрия питания для формирования направленного луча
3. Рассчитать направленность (dBi) и коэффициент усиления матрицы 4×4.
4. Предусмотреть экранировку от самовозбуждений и паразитных токов:
   - Металлическая камера вокруг антенной решётки (стенки толщиной ≥ 1.5 мм, алюминий)
   - Отдельные области для каждого канала с экранированием
5. Разработать трассировку в KiCad / Altium — файл `block3.kicad_sch` / `.kicad_pcb`.
6. Провести электромагнитное моделирование (HFSS/CST или открытые альтернативы).
7. Свести моделирование с экспериментом (после изготовления прототипа).

## Критерии приемки
- Резонансная частота: 5.8 ± 0.05 ГГц
- Диапазон работы: 4.0–7.0 ГГц (SWR ≤ 2.0)
- КНД: не менее 12 дBi (матрица 4×4)
- Входное сопротивление: 50 ± 5 Ом
- Экранирование от паразитных излучений: уровень сторонних лепестков ≤ −15 дБ
