# tests/requirements/emc/
Тесты электромагнитной совместимости (ЭМС) по требованиям REQ-21…REQ-25.

## Что тестируется
- REQ-21: экранирование из фрезерованного алюминия — скин-слой δ ≈ 0.025 мм при 1 ГГц,
  эффективность экрана SE ≥ 40 дБ (стенка 1 мм даёт >100 дБ), контактное сопротивление
  RF-прокладок ≤ 10 мОм (MIL-DTL-83528), диапазон 0–7 ГГц.
- REQ-22: иммунитет к внешним ЭМ-полям — ГОСТ 30804.4.3-2013 / IEC 61000-4-3
  (уровень жёсткости 2 = 3 В/м, 80–2700 МГц); индуцированное напряжение V = E·h = 0.3 В,
  мощность P = V²/R при 50 Ом; требуемое подавление 40–60 дБ, сохранение ДД 85–100 дБ.
- REQ-23: норма эмиссии ГОСТ CISPR 22-2012 (Класс Б) / EN 55022; излучение Wi-Fi
  после экранирования ≤ −30 дБм/м; линейные стабилизаторы + 0.1 мкФ.
- REQ-24: фильтры питания — fc = 1/(2π√(LC)); ferrite beads R_f ≈ 100 Ом на 100 МГц.
- REQ-25: зонирование корпуса (3 зоны: ВЧ / оптическая / цифровая), гальваническая
  изоляция (связь с ПК только по Wi-Fi).

## Как запускать
.venv/bin/pytest tests/requirements/emc/ -v
